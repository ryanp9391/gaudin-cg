## 5. Not a table but a statement
"Each operator becomes Jacobi on a certain subspace": TRUE for V3 and V4a on every P_κ (the Jacobi chain is the gl(3) chain with κ-dependent scale a and shift b); V4b is Jacobi on P_κ but with the [ξ,V] + ξ + ξ² correction; the full operator is then "Jacobi chains on the paths κ + dense full-rank hopping between paths κ, κ ± root". It is not "recursive from the bottom" as in gl(3): the dense hopping blocks tie all κ together at once.

## 6. Surprises and corrections
1. B1 is true for V3 and V4a with a(κ) independent of λ′ and ν and equal to 1 at κ = λ_123. The brief expected "a(κ) ∝ Q6-ratios"; a is a rational number depending on (κ, λ), not a product of linear forms; the explicit form is open.
2. V4b: the failure is exactly a commutator with the gl(2)₁₂ Casimir (fit with five parameters; the g = −e/4 relation holds in all 42 non-degenerate cases).
3. The brief's end-point hypothesis for the hopping blocks (T ∝ p_end p_end) is false; dense, full rank.
4. Depth: the brief's n = ν4 coincides with the true depth only when λ4 = 0 (for λ4 > 0, depth = ν4 − λ4, and V4a = V4b = 0 is replaced by J^{(4a)} = V^(3) + b, J^{(4b)} = −V^(3) + b; "V4a = V4b = 0 when μ4 = 0" should read "when d = 0 and λ4 = 0").
5. dim M~ = m exactly iff E34^{k3} is void (n < λ′_3 − λ′_4 + 1): a clean dichotomy (239 + 83 sectors); M~ is a PRV-type space of the nested chain whose first deviation from M_μ is the E34 string.
6. "Rank of c(κ,s)" is always full: no factorisation of physical copies over κ and s.

## 7. Not done / limits
* Closed forms of a(κ), b(κ) as functions of (κ, λ, λ′, ν): only the tables, the λ′/ν independence of a, the polynomial degree of b (quadratic in ν, affine in λ′ for V3 at κ = (5,3,0); b_4a = const for κ3 = 0) and one explicit b_3 — no general formula, no held-out verification of a closed form (none was found).
* No analytic relation between the gl(4) eigenvalues v3 and the gl(3) eigenvalues was found or searched beyond looking at the tables.
* B3: the Δm12 = 0 hopping classes (cubic Q) were not evaluated against `explicit_q_block`; only the 12 universal classes (5214 tests) were. The hopping blocks in the nested basis were not expressed in closed form (they are B′⁺HB numerically; the structure is dense/full rank).
* The paths in P_small ∪ P_big have ≤ 3–4 points (5 in the held-out run), so tests of the ξ² term of V4b and of long-chain statements are limited to |P| ≤ 5. Larger λ would test the claims on longer chains but was not run.
* No proofs. The identification B0 is a statement about the GT formulas (rows 1–3 only), which can be proved by inspection; B1 is exact data.
