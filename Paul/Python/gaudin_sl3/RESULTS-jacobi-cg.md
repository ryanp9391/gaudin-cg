## 0. Conventions and objects

* GL3Rep order (ascending lexicographic in (m₁,m₂,t), HW state last), plain rational GT normalisation, E₁₃ = [E₁₂,E₂₃], V_red and slice as in R (SPEC §1). Λ = [λ₁,λ₂,λ₃] arbitrary (λ₃ ≥ 0 allowed), μ dominant, |μ| = 2|Λ|.
* **Chain 1** (the weight space W = V_Λ[μ−Λ] in the GT basis): t = μ₁−λ₁ and s = m₁+m₂ = (μ₁−λ₁)+(μ₂−λ₂) are fixed by the weight, **m₁ is the running coordinate** (m₂ = s−m₁); position k ↔ m₁ = lo+k, lo = max(λ₂, s−λ₂, t, s−t), hi = min(λ₁, s−λ₃), w = hi−lo+1; the 0-based GL3Rep index of {t;m₁,m₂} is `gt_index` (closed form, = R's W). Write x = m₁−m₂, ξ = x(x+2) = 4j(j+1) (j = gl₂ spin).
  M[k,k] = α_k, M[k+1,k] = u_k, M[k,k+1] = d_k (M[row,col] = coefficient of e_row in V_red e_col), nothing else.
* **Cut** (E₁₂ constraint): m₁ ≤ μ₁−λ₂; w₁ = #positions below the cut; W₁ = span of them.
* **Chain 2**: V′ = U V_red U⁻¹ with U = the Weyl element w₀ (E_ij → E_{4−i,4−j}); V′ is the same 36-term formula with Φ′_cc = λ_{4−c}, Φ′_ab = −E_ab for a > b, 0 for a < b, acting on W′ = V_Λ[(e₃,e₂,e₁)], (e₁,e₂,e₃) = μ−Λ: t′ = μ₃−λ₃, s′ = (μ₃−λ₃)+(μ₂−λ₂), cut m₁ ≤ μ₂−λ₃ (E₂₃^{λ₂−λ₃+1} becomes E₂₁^{λ₂−λ₃+1}, diagonal in the same GT basis); w₂ = #positions below the cut.
* Slices: first nonzero component (the lowest m₁) = 1, ascending V per sector, R's COPY convention. V sources: R's eigenvalues, Q0's V (30 digits), S's pencil (b → V = q − b/2 − η/2), or the chain itself.

## 1. Headline results

1. **Yes, with closed forms.** On the weight space W the formula-defined V_red is tridiagonal in the GT basis for a structural reason (24 of the 36 terms are nonzero; in each exactly one factor has first index 3 and exactly one has second index 3 — E₃₃×(two gl₂-generators) or E_{a3}×E_{3b}×(one gl₂-generator) — and E₂₃/E₃₂ move exactly one of m₁, m₂ by ±1, so the net shift of (m₁,m₂) is 0 or ±(1,−1)). The three diagonals are explicit rational functions (§3), **derived symbolically for generic labels (sympy, 36 terms, all intermediate states kept), not fitted**; they reproduce R's exact V_red entry for entry on **39 608 dominant weights of 968 reps** (every [l₁,l₂,l₃] with l₁ ≤ 16, λ₃ ≥ 0; 0 mismatches), and the 19-rep list of §2 (1 230 sectors, 5 232 states, incl. [4,2,0], [6,3,0], [8,4,0], [14,7,0], [20,10,0], [28,14,0]).
2. **The slice of a copy is the forward three-term recurrence at its V**: p₀ = 1, p₁ = (V−α₀)/d₀, p_{k+1} = ((V−α_k)p_k − u_{k−1}p_{k−1})/d_k on the E₁₂-truncated chain W₁, zero beyond. `slice_from_V` reproduces **all 19 + 44 + 85 + 344 + 891 + 2255 = 3 638 copies** of [4,2,0], [6,3,0], [8,4,0], [14,7,0], [20,10,0], [28,14,0] (2 747 of them are the five reps of the brief) against R at 50 digits: max relative deviation **4.4e-50 / 1.4e-49 / 1.8e-48 / 1.5e-46 / 8.2e-45 / 4.1e-42** (the 4e-42 floor at a = 14 is R's `mp.eig`: at 80 digits **6.6e-78 ([14,7,0]) and 1.05e-73 ([28,14,0])**); a further **848 copies of 12 other reps — [10,3,0], [9,1,0], [12,5,0] and nine with λ₃ > 0 ([3,2,1] … [15,8,4]) — agree with R's engine run in memory to ≤ 5.7e-48** (chain-only V). An independent test needing no R eigenvectors — the recurrence slice satisfies E₁₂^{λ₁−λ₂+1}v = E₂₃^{λ₂−λ₃+1}v = 0 and V_red v = V v exactly — passes for 6 796 copies of 285 reps (λ₁ ≤ 10, λ₃ ≥ 0): worst residual 1e-39 / 1e-46, 0 failures; and the 587 NON-physical eigenvalues of V_red|W₁ all violate the E₂₃ constraint.
3. **J3 (a) or (b)? Both occur, and they are the two halves of a symmetric statement.** E₁₂ is diagonal in the chain coordinate, so its constraint is a coordinate cut m₁ ≤ μ₁−λ₂, and V_red leaves the initial segment W₁ invariant because the factor (μ₁−λ₂−m₁) of u vanishes exactly at the cut. The E₂₃ constraint is the same kind of coordinate cut in the **second chain** V′ = U V_red U⁻¹ (cut m₁ ≤ μ₂−λ₃). The two constraints are never both active (the image weights need μ₂ ≥ λ₁+λ₃+1 resp. μ₂ ≤ λ₁+λ₃−1 — a weight of V_Λ has every E_ii in [λ₃,λ₁]). Hence: **μ₂ ≥ λ₁+λ₃ ⇒ M_μ = W₁ (a coordinate sub-chain of chain 1, m = w₁); μ₂ ≤ λ₁+λ₃ ⇒ U M_μ = W₂ (a coordinate sub-chain of chain 2, m = w₂).** In chain 1 the second case is a spectral subspace of an irreducible Jacobi matrix (the m largest eigenvalues, exact on all data). At [14,7,0]: 71 sectors w = w₁ = m (free), **21 with w > w₁ = m (E₁₂-cut: the recurrence truncates)**, **21 with w = w₁ > m (E₂₃-spectral)**, none of both; for [2a,a,0]: C(a,2) + C(a,2) + (a²+3a+1) sectors (a = 1..20 checked). ## 3. J2: closed forms, characteristic polynomial

With t, s, m₂ = s−m₁, x = m₁−m₂, ξ = x(x+2) (chain 1; each factor is a linear form in the GT labels):

```
u(m1) = M[m1+1,m1] = -(l1-m1)(l2-m1-1)(l3-m1-2)(t+1-m2)(mu1-l2-m1) / ((x+1)(x+2))
d(m1) = M[m1-1,m1] = -(l2-m2)(t-m1)(l1-m2+1)(l3-m2-1)(mu1-l2-m2+1) / (x (x+1))          (the entry M[k,k+1] is d at m1 = lo+k+1)
```

* **Derivation**: `derive_symbolic` applies the GT formulas to the generic state {t;m₁,m₂} with symbols t, m₁, m₂, λ₁, λ₂, λ₃, through the 36 terms (E₁₃, E₃₁ as commutators), keeps all intermediate states (no boundary treatment), and obtains exactly three weight-zero components (m₁ shifted by +1, 0, −1); `sp.cancel` shows the three are identical to the closed forms above (exact sympy equality), and the exact-Fraction Python functions agree with the symbolic result at 600 random generic integer points (0 mismatches), for chain 1 and chain 2. The boundary subtlety (raw GT formulas propose nonzero coefficients into out-of-range states) is covered by the exact comparison with R's matrices at every valid state of 39 608 weights (including all corner states m₁ = m₂ = λ₂). **No data were used to guess the formulas, so every rep tested is out-of-sample; [28,14,0] (421 sectors) and [20,10,0] were checked in full.**

* **Off-diagonal products** (the invariant of a Jacobi matrix; checked on 2 735 adjacent pairs): for the pair (m₁, m₁+1), m₂ = s−m₁, x = m₁−m₂,
  `u d = A1·…·A10 / ((x+1)(x+2)²(x+3))`, A1 = λ₁−m₁, A2 = m₁+1−λ₂, A3 = m₁+2−λ₃, A4 = t+1−m₂, **A5 = μ₁−λ₂−m₁**, A6 = λ₂−m₂+1, A7 = m₁+1−t, A8 = λ₁−m₂+2, A9 = m₂−λ₃, A10 = μ₁−λ₂−m₂+2.
  For two adjacent positions both in W₁ every A_i is a positive integer (the A's are distances to the walls of the GT range), hence **u d > 0**, and individually **u < 0, d < 0** on W₁ (proof by the signs of the factors; confirmed in 113/113 and 421/421 sectors). At the cut A5 = 0; beyond it A5 < 0 and the product is negative. So V_red|W₁ is a Jacobi matrix with simple real spectrum and (all off-diagonals negative) the i-th eigenvector (ascending) has exactly i−1 sign changes in the plain GT basis (Sturm; checked on 455/455 and 56/56 physical eigenvectors of the E₂₃-sectors).
* **Characteristic polynomial**: continuant D₀ = 1, D₁ = x−α₀, D_{k+1} = (x−α_k)D_k − u_{k−1}d_{k−1}D_{k−1} (`Chain.contin`). Relation to R's CHARPOLY (exact, `parse_ref`): **D_{w₁} = CHARPOLY in 92/92 sectors with w₁ = m at [14,7,0]** (12/12, 22/22, 35/35 at [4,2,0], [6,3,0], [8,4,0]); **CHARPOLY divides D_{w₁} in the 21/21 sectors with w₁ > m** (1/1, 3/3, 6/6), and the cofactor's roots are all smaller than the physical ones (smallest gap physical-min − other-max: 18, 24, 30, 48). Relation to the Q-side polynomial: §6.

## 4. J3: the PRV subspace inside the chain

* **E₁₂ is diagonal in the chain basis**: E₁₂ e(t,m₁,m₂) = (m₁−t)(t+1−m₂) e(t+1,m₁,m₂), so E₁₂^{λ₁−λ₂+1} e ≠ 0 iff m₁−t ≥ λ₁−λ₂+1 iff m₁ ≥ μ₁−λ₂+1: M_μ lies in W₁ = {m₁ ≤ μ₁−λ₂} (113/113 at [14,7,0], 421/421 at [28,14,0], 31 976/31 976 in the scan; R's exact PRV vectors have no support beyond the cut). u(μ₁−λ₂) = 0 ⇒ W₁ invariant (cut u = 0 in 21/21, 91/91, 4 956/4 956).
* **E₂₃ is the same in chain 2**: U M_μ = {v′ ∈ W′: E₃₂^{λ₁−λ₂+1}v′ = E₂₁^{λ₂−λ₃+1}v′ = 0}; E₂₁^{λ₂−λ₃+1} keeps m₂ ≥ t′−(λ₂−λ₃), i.e. m₁ ≤ μ₂−λ₃; u′ vanishes there (421/421 at [28,14,0], 31 976/31 976 in the scan) and the products are > 0 on W₂ (all sectors).
* **At most one constraint is active.** Image weight of E₁₂^{λ₁−λ₂+1} on W: (t+λ₁−λ₂+1, e₂−(λ₁−λ₂+1), e₃) has E₂₂ = μ₂−λ₁−1, which must be ≥ λ₃: μ₂ ≥ λ₁+λ₃+1. Image weight of E₂₃^{λ₂−λ₃+1}: E₂₂ = μ₂−λ₃+1 ≤ λ₁: μ₂ ≤ λ₁+λ₃−1. (A weight of a gl₃ irrep has all E_ii ∈ [λ₃,λ₁].) Checked: E₁₂ effective ⇔ its image weight exists (31 976/31 976); never both effective (31 976/31 976); μ₂ ≥ λ₁+λ₃ ⇒ m = w₁ and μ₂ ≤ λ₁+λ₃ ⇒ m = w₂ (31 976/31 976 each).

## 6. J5: the Q-side meaning

1. **Sizes and products.** Baxter (S): chain index N = 0..d_j, d = (μ₃, μ₂+1, μ₁+2), α_{N−1}p_{N−1} + (β⁰_N + b/2)p_N + ρ_{N+1}p_{N+1} = 0, off-diagonal product α_Nρ_{N+1} = (N−μ₃)(N−μ₂−1)(N−μ₁−2)(N+1)(N−λ₂)(N−λ₁−1), diagonal cubic in N, spectral parameter b/2 = q−V−η/2 entering linearly. GT chain: length w₁ ≤ 8 (≤ 15 at a = 14), products with ten numerator roots and the denominator (x+1)(x+2)²(x+3), diagonal A₀ + g₁ξ − K/(16ξ), V entering linearly on the diagonal. Examples (roots in N resp. m₁): (21,14,7): Baxter {−1,7,7,15,15,23} vs GT numerator {−2,−2,−2,6,6,6,6,14,14,14}, lengths 8/16/24 vs 8 (the lengths coincide here: w₁ = μ₃+1); (22,10,10): {−1,7,10,11,15,24} vs {−6,−5,−2,2,3,6,7,11,14,15}, lengths 11/12/25 vs 4; (14,14,14): lengths 15/16/17 vs 1. At [14,7,0] w₁ = d₁+1 in only 36 of 113 sectors. **The two products are not diagonally similar (one is a rational function with poles, the other a polynomial), the chains are different sizes, so the recurrences are different.**
2. **What they share, exactly.** (a) The spectral dictionary V = q − b/2 − η/2 (diagonal-linear). (b) The physical characteristic polynomial: S's gcd polynomial (V-mapped, monic) = R's CHARPOLY in 13/13, 25/25, 41/41, 113/113 sectors (g is already squarefree in all of them); = D_{w₁} when w₁ = m (92/92), divides D_{w₁} when w₁ > m (21/21); = the continuant of V′|W₂ in the E₂₃-spectral sectors. (c) Q0's closed forms V = α − η/2 (m = 1) and the mean rule (2 510 / 6 255 sectors, λ₃ = 0, l₁ ≤ 15) — consequences of the chain.
3. **Which Baxter system carries what** (S's three echelon systems, single-system polynomials, exact; [14,7,0]: the 21 + 21 special sectors and the sectors with μ₁ = 2λ₁ or μ₃ = 0, 57 in all; all of [4,2,0], [6,3,0], [8,4,0]): the gcd of all three has degree m in every sector. **In the E₂₃-spectral sectors the system P₂ ALONE already has degree m (21/21 at [14,7,0], 6/6, 3/3, 1/1 at the smaller reps) and gcd(P₁,P₃) over-counts; in the E₁₂-cut sectors P₃ ALONE has degree m (21/21, 6/6, 3/3, 1/1) and gcd(P₁,P₂) over-counts** — exactly S's/Q0's failure of the two-system gcd (the shipped `pencilSolve`), which is therefore the E₁₂-cut regime. In the E₁₂-cut sectors gcd(P₁,P₂) ⊇ the continuant of the full chain on W (physical ∪ the quotient block beyond the cut) times extra roots, e.g. (5,5,2) of [4,2,0]: gcd = (x−25)(x−43)(x−7) with continuant(W) = (x−43)(x−25).
4. **Regression slice ↔ Q polynomials** (R's file slices, 30 digits, against Q0's QPOLY; per sector with m ≥ 2, ratio constancy over the copies, tolerance 1e-7; the Q columns are the 3 monomial-coefficient lists (= Taylor coefficients at the site u = 0), the Taylor coefficients at u = 1, and the values at u = −1, 2, …, 10 of q₁, q₂, q₃): test A (s_j ∝ q_i) 1 332 / 3 597 / 26 945 pairs at [6,3,0] / [8,4,0] / [14,7,0], hits 0 / 2 / 0; test B (s_j ∝ q_i/q_i₀) 87 472 / 272 212 / 2 853 126 pairs, hits 33 / 99 / 93. **Every hit sits on the LAST slice component (j = w₁, largest m₁) except 35 and 10 hits in the m = 2, 3 sectors (11,7,6), (12,7,5) of [8,4,0] and (17,13,12), (25,9,8) of [14,7,0] on the affine component p₂** (a function affine in V can coincide in direction with another affine function on two or three points). A first, Gram-matrix version of the test produced dozens of false positives (vectors dominated by one copy) and a trivially-zero family (q₁ has degree < λ₂+1, so its Taylor coefficient of order λ₂+1 vanishes): the final criterion is constancy of the ratio with all entries non-vanishing.
   **The last component** (survey with one q_k, two Taylor orders a ≠ b, one site): s_w₁ · q_k^{[a]}(site)/q_k^{[b]}(site) = const over the copies exists in 9/13, 17/25, 39/85 multi-copy sectors of [6,3,0], [8,4,0], [14,7,0]; the frequent families are all at the site u = 1; dominant family (k = 2, a = λ₂+1, b = 0): 7/13, 11/25, 31/85 (the resonance ratio of the Frobenius expansion at the site, exponent difference λ₂+1); second family (k = 3, (λ₂, λ₁+1)): 7 sectors at [14,7,0]. For the other sectors no two-coefficient ratio works. These ratios look like normalisation/Jacobian data of the Q-function (for a Jacobi matrix the product of the first and last components of the normalised eigenvector is Πb_k/χ′(V_c), so s_last/Σg_k s_k² ∝ 1/χ′(V_c); s_last·χ′(V_c) itself is not copy-independent — 0 of 70 sectors with w₁ = m — because the copy-dependent norm enters), not direction data.
   **Conclusion**: there is **no exact map from QPOLY coefficients (or their jets at the sites, or integer values) to the slice**: components 2…w₁−1 never follow a two-term proportionality, the last component does in 39/85, 17/25, 9/13 of the multi-copy sectors. The Q-function information that fixes the slice direction is V alone (equivalently the first Laurent datum a₁ = V + η/2, η = η₁ = |Λ|²+cas₂(Λ)−cas₂(μ)/2): **slice_k = p_{k−1}(a₁ − η/2), a polynomial of degree k−1 in the accessory parameter**; the slice ratio s₂/s₁ = (V−α₀)/d₀ and V = α₀ + d₀ s₂/s₁ (the accessory parameter is a linear function of the first slice ratio).

## 7. J6: the statement and the complexity

**Theorem (Jacobi form of the SoV copies, gl(3); Λ arbitrary, μ dominant, |μ| = 2|Λ|).**
(T1) *[proved: structure + symbolic derivation; exact on 39 608 weights / 968 reps]* V_red is tridiagonal on the chain of W with u, d, α as in §3.
(T2) *[proved from the closed form]* E₁₂^{λ₁−λ₂+1} is diagonal in the chain basis and kills exactly the components with m₁ > μ₁−λ₂; u(μ₁−λ₂) = 0, so W₁ is V_red-invariant; on W₁ the products u d = A₁⋯A₁₀/((x+1)(x+2)²(x+3)) are positive (u, d < 0), so V_red|W₁ is a Jacobi matrix with simple real spectrum; beyond the cut the products are negative.
(T3) *[proved from the same computation for V′ = U V_red U⁻¹]* the same for chain 2 with E₂₁^{λ₂−λ₃+1} and the cut m₁ ≤ μ₂−λ₃.
(T4) *[proved from the PRV theorem and the weight polytope; exact against Racah–Speiser on 39 608/39 608 weights]* at most one of the two constraints is non-void: μ₂ ≥ λ₁+λ₃ ⇒ M_μ = W₁ (coordinate sub-chain), m = w₁; μ₂ ≤ λ₁+λ₃ ⇒ U M_μ = W₂, m = w₂. This is a closed-form multiplicity.
(T5) *[consequence of T2–T4]* The V-spectrum of the sector is the spectrum of the explicit m×m Jacobi matrix V_red|W₁ (μ₂ ≥ λ₁+λ₃) or V′|W₂ (μ₂ ≤ λ₁+λ₃).
(T6) *[consequence of T2 + simple spectrum]* For every eigenvalue V of the sector, **the slice of the corresponding copy is p₀ = 1, p₁ = (V−α₀)/d₀, p_{k+1} = ((V−α_k)p_k − u_{k−1}p_{k−1})/d_k on W₁, zero beyond**; it is unique up to scale.
*Verification status.* Proved by construction/computer algebra: T1–T3 and the sign statements; T4 up to the PRV theorem (cited). Checked exactly on finite data: T1–T4 on 968 reps; T5 against R's exact CHARPOLY (113/113, …) and, for [20,10,0], [28,14,0] and the scan, against R's eigenvalues; T6 at 50 digits on 3 638 copies and at 80 digits on 2 599, plus the direct PRV/eigen-equation test on 6 796 copies. **Inherited, not re-derived here**: the identification of V_red's eigenvalues with the Q-system's roots (R, Q0, S: exact on all 492 branches ≤ [14,7,0]; re-checked here at 30 digits against Q0's 473 + 891 + 2 255 copies and at 50 digits against S's 344 + 85 + 44 + 19 + 37). **Conjectured (checked on 31 976 sectors, mechanism but no proof)**: when E₂₃ is active, the physical eigenvalues are the m largest of V_red|W; the identity for all Λ with λ₃ > 0 of the Q-system conventions (α = (μ₁+2)(μ₂+1)μ₃/2 with the central shift) was not examined.

## 8. Surprises and pitfalls

* The closed forms are *so* factorised (ten linear factors in the product) that the structure is not specific to Λ = [2a,a,0] or λ₃ = 0: it holds for every gl(3) irrep and was found by plain symbolic composition of the GT formulas; the only non-factorising piece is the cubic A₀.
* The second chain: V′ = U V_red U⁻¹ is the same operator with a lowering Φ′; U is a Weyl element, not the Dynkin automorphism (E_ij → E_{4−i,4−j}, not −E_{4−j,4−i}); in the (12)-adapted basis E₂₁ is diagonal, which is what turns the E₂₃ constraint into a coordinate cut. In free sectors chain 1 and chain 2 are isospectral (the exact continuants agree 71/71); in (21,14,7) chain 2 is minus chain 1 plus 2058 (α′_k = 2058 − α_k, u′ = −u, d′ = −d).
* The statement "E₁₂-cut sectors are Jacobi on W" is false (negative products beyond the cut), "w > m ⇒ non-Jacobi" is false (E₂₃-spectral sectors are Jacobi with w > m).
* **A precision trap in my own tests**: `mpmath.fsum`/`sum` and `mpf − Fraction` outside a `workdps` block round to the default 15 digits; a first version of the "mean of V over the copies" test reported 148 spurious failures of size 1e-15 that vanished at 50 digits (0/6 255).
* The obvious hypothesis "the G-norm of the full HW vector is diagonal in the chain basis" (ratio of consecutive weights d/u, which would make the Jacobi matrix self-adjoint for the induced norm) fails: GNORM2/(Σ q_k s_k²) varies by up to 0.99 across the copies of a sector. The induced form on M_μ is not diagonal in the chain basis (V_red is self-adjoint for it, but not through the diagonal metric).
* The first version of the regression (Gram/rank-1 criterion) gave false positives dominated by the dynamic range of the copies; the final criterion is ratio constancy with non-vanishing entries.
* Shell trap (as R noted): backslash escapes inside Bash heredocs are mangled; patches containing quotes were applied with the file tools or via script files.

## 9. Not done / limits

* The identification (Q-system root) = (V_red eigenvalue) is taken from R, Q0, S, not re-derived; the Q-polynomial coefficient regression covers only Q0's files ([6,3,0], [8,4,0], [14,7,0], λ₃ = 0, equal sites).
* Slices only: the full HW vector from a slice is R's recursion (`hw_from_slice[_rounded]`, not rerun); absolute normalisation and sign of the copies are untouched (only "first nonzero = 1"; the Q-side norm of round 5 is not used).
* The Weyl operator U (the change between the (12)- and (23)-adapted GT bases) was not constructed: chain 2 gives eigenvalues, not slices; the slice always comes from chain 1's recurrence (valid in every sector, with V from either chain or from the Q-system).
* Slices for λ₃ > 0 are compared with R's engine run in memory (nine reps, 488 copies, ≤ 5.7e-48), with the direct PRV/eigen-equation test (285 reps) and the eigenvalue/multiplicity scans — not with a ref file (R wrote none) and not with any Q-system data (Q0/S cover λ₃ = 0 only); `qdata` is λ₃ = 0 only.
* The top-m ordering of the physical eigenvalues in the E₂₃-spectral sectors is exact on 31 976 sectors but unproved (the rigorous chain-2 rule makes it unnecessary for the algorithm).
* The regression stops at ratios of two Taylor coefficients; a full dictionary for the interior components would have to involve Wronskian-type minors of the jets (as in the jet formula) — not explored.
* S's pencil at [28,14,0] only on 6 sampled irreps (the whole family is hours); R's file for [28,14,0] was generated in memory, not written (`slice_engine.py ref 28 14` would write `ref/cg-slices-28140.txt`).
* No git operations, no notebooks, no file outside `Paul/Python/gaudin_sl3/` written.
